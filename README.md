# Wireless Hit Counter — счётчик попаданий по стальному гонгу

Автономная система для определения попаданий в металлический гонг на стрельбище, с передачей события по радио на хост у стрелка.

## Что делает

Узел-датчик крепится на гонг, ловит удар пьезоэлементом и отправляет событие по LoRa на узел-счётчик у стрелка. Хост увеличивает счётчик, подаёт звуковой сигнал и показывает состояние радиосвязи. Дальность — от 200 м, с запасом под открытую местность.

## Статус проекта (на 14.09.2026)

- **Счётчик:** ESP32-C3 + TM1637 + buzzer + кнопка спаяны. Трансивер физически не установлен. Залита тестовая прошивка-заглушка (счётчик по кнопке).
- **Датчик:** ESP32-C3 + LM393 + пьезодиск + E220-400T22D с антенной — собраны. Прошивка не залита.
- Прошивка (heartbeat, детектирование удара, радиопротокол) — в разработке.

Подробный статус и план — см. [docs/spec.md](docs/spec.md), разделы 10 и 12.

## Архитектура

Два узла на ESP32-C3, связь по LoRa (Ebyte E220-400T22D, 433 МГц):

- **Узел-датчик** — LM393-компаратор + пьезодиск на гонге, батарейное питание (4×AA лития).
- **Узел-счётчик** — дисплей TM1637, buzzer, кнопка сброса, светодиод состояния связи, питание от powerbank.

Протокол устойчив к повторной передаче пакетов (EventNumber исключает задвоение счёта).
