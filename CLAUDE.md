# CLAUDE.md

Контекст для Claude Code в этом репозитории.

## Обязательно прочитай перед началом работы

- `docs/hit-counter-kit-spec_v3.md` — архитектура, обоснования решений, радиопротокол, roadmap, **и текущий статус сборки (раздел 10)**.
- `docs/hit-counter-pinout.md` — актуальная распиновка обоих узлов.

Эти файлы — единственный источник истины по железу и статусу. Не дублируй их содержимое сюда и не придумывай пины/параметры/статус по памяти — при любой задаче сверяйся с этими файлами заново, они могли обновиться.

- **Объясняй код и IT-концепции как новичку.** Без жаргона без пояснений, коротко.
